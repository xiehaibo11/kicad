工具发现与引用参考
https://learn.chatgpt.com/docs/app-server
- mcpServerStatus/list: server tools, resources, auth status.
- skills/list: workspace-scoped skill discovery.
- app/list and app/read: connector discovery and tool summaries.
- model/list: model capabilities and reasoning options.
- dynamicTools + item/tool/call: experimental custom client tool execution flow.
Tool declarations and argument schemas enable model tool calls. Prompt suggestion text itself does not authorize or execute those calls.

KiCad adaptation direction (proposal, not implemented here)
Keep current-model prompt optimization separate from next-message suggestions.
If next-message suggestions are added: generate after completed turn; show only in empty editor; accept into draft with Tab; preserve explicit manual send; hide on typing/session changes; ignore stale output.
Build KiCad tool/reference entries from the real MCP catalog, including read/write distinction and prerequisites, rather than hardcoding nonexistent capabilities.
