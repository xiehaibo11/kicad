Kicad 0.4.18 检查说明

本次修复
1. 暂停后立即重新发送：旧通道立即退出界面接收；后端中断并关闭旧 SDK 进程；下次手动发送恢复原会话。
2. 保留会话目录、模型、推理强度和权限。旧事件、旧错误和旧流结束回调不会清除新请求状态。
3. 清理旧权限确认，拒绝已结束通道的迟到确认；单次启动失败不再终止消息分发。
4. 每次请求的工具参数、原始输出、思考和中间进度合并到运行记录，默认折叠，点击或键盘展开/收起。
5. 重要问题、需确认事项、错误摘要和最终回复保持可见。必要权限确认不折叠，原始记录保留。
6. 子代理的中断和结果不会结束主任务或隐藏主任务最终回复。

验证证据
- build.sh：TypeScript、Vue 类型检查及完整扩展回归检查通过。
- production-ui-verification.json：正式 Webview 包的交互检查，含默认折叠、完整详情、错误、权限、320px、暂停后立即重发与迟到事件隔离。
- pause-sdk-verification.json / pause-host-requests.json：真实 VS Code 服务与固定版本 SDK/CLI；本地 Messages API 模拟模型返回，实际启动子代理，中断后确认旧进程退出，恢复原 session 并仅接收一次重发请求。
- ../dashboard-0.4.18/verification.json：子代理看板和模型菜单回归；阻塞 SDK 模型发现时仍可选择模型。
- ../composer-ui.json：提示词、权限、推理强度和 Tab 下一句建议回归。
- installed-verification.json：安装版本与正式包内容及前后端构建文件哈希一致。

手动检查
在新版检查窗口中输入一个任务，发送后点击停止；随即输入新的消息并发送。
新消息应收到正常回复，上一轮显示已停止，不应自动重发旧消息。
执行工具时点击“运行中 / 点击查看”，可展开日志，再次点击可收起。
本次本地协议测试没有使用外部付费模型，也没有修改 PCB 或原理图。
